# SF-POLY Alpha 2 — 80 factory presets

Four banks of 20: Juno-106, Polysix, Prophet-5, Hybrid.

Each bank contains Strings (4), Pads (4), Bass (3), Brass (2), Leads (2), Keys (2), Arpeggios (2), and Drones (1).

The preset dropdown is grouped by engine and category (e.g. "Juno-106 / Strings"). Each factory preset recalls the relevant engine enable switches and fader levels, as well as common synthesis settings. Hybrid presets cover pairs and all-three combinations. Arpeggio patches activate the existing arpeggiator. User patch storage remains separate.

These are 80 deliberately parameterised starting patches, not yet ear-tested or measured against vintage hardware. The existing sequencer remains monophonic. No new synthesis DSP was added in this preset-only update.
